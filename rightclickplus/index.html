RightClick+

A handful of focused, everyday file actions for the Windows right-click menu, each one you can switch on or off from a simple control panel. Portable, no background service, no admin rights.

⬇ Download v1.0.5 View source
C# / WinUI 3 · .NET 10 · Portable · MIT licensed

What it adds

📁 File to Folder

Select loose files and drop each one into its own new folder named after it. Works on a multi-selection, merges into existing folders, and handles name clashes.

📝 File Note

Jot a dated note right next to a file (.txt or .md) so future-you remembers why you kept it. The note travels with the file.

📋 Copy File Names

Copy a file's name, name without extension, full path, or quoted path. Select several and they copy together, one per line or comma-separated.

🎨 Folder Color

Recolor a folder icon from 11 colors so the ones that matter stand out. Self-contained, so the color travels with the folder, even to another PC.

🧹 Classic or Modern menu

One click switches Windows 11 between the Classic and Modern right-click menu, so your actions sit on the top level without "Show more options".

🔒 Portable & private

Every entry is written under your own user account (HKCU). No admin, no UAC prompt, no background service, no telemetry. Toggling a feature off removes it cleanly.
